# Contributing to Buku Wajib Developer

## 🚀 Sebelum Mulai
1. Baca `00-README.md` untuk paham arsitektur.
2. Install tools: Node.js, Git, GitHub CLI (`gh`).

## 🌿 Branch Strategy
- `main` → production-ready
- `develop` → integration branch
- `feature/nama-fitur` → untuk fitur baru
- `fix/nama-bug` → untuk bug fix

## 📝 Commit Convention
feat: menambahkan fitur X
fix: memperbaiki bug Y
docs: update dokumentasi
refactor: refactor kode tanpa ngubah behavior
test: tambah test

text

## 🔄 Pull Request Process
1. Pull terbaru dari `develop`.
2. Buat branch dari `develop`.
3. Commit dengan format di atas.
4. Push dan buat PR ke `develop`.
5. Minimal 1 review sebelum merge.

## 📦 Sebelum Commit
- [ ] `git add .` — pastikan file `.env` gak ke-track!
- [ ] `git commit -m "type: pesan jelas"`
- [ ] `git push`

## ❓ Ada masalah?
Baca `03-ADVANCED.md` atau tanya di grup.
